# 主号操作手册

给 YCH（维护者）自己用。完整指令表见同目录 `COMMANDS.md`。仪表盘左侧也有「操作手册」，内容和这里一致。

## 现在在干什么

机器人 `2000000002` 会自动回：

- 所有私聊
- 它所在的群，但必须真实 `@` 它

搜索、文生图、隐私删除执行、OCR 关着。空间资料必须你指定某个 QQ 才会去翻。

本机挂着才能回。电脑休眠、YCH 或 NapCat 停了，就不会回。

## 每天怎么开

1. 确认 NapCat 登的是机器人，不是主号。
2. 确认 YCH 在跑，仪表盘能打开。
3. 私聊机器人发 `/机器人 状态`，有效模式应是 `auto`，且没有暂停。
4. 要停：`/机器人 暂停`。

## 怎么认人

仪表盘「操作手册」页有一张「备注」卡，能看全部备注，也能给用户或群改备注。用户页也能在身份卡里改。列表先显示备注，QQ 在下面。

也可以私聊机器人：

```text
/用户 2000000003 备注 小明
/群 2000000004 备注 测试群
/用户 2000000003 备注 清除
```

备注只给你看，不进模型，不改变谁会被回复。

## 指令从哪发

只在主号 `2000000001` 和机器人的**私聊**里发 `/` 命令。群里同一句话当普通聊天。别人在文字里自称主号无效。
