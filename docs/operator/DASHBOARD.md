# 仪表盘怎么认人

打开 `http://127.0.0.1:5173`，用管理令牌登录。不要把令牌写进文档或聊天。

## 操作手册页

侧栏「操作手册」是认人和查指令的主入口：每天规则、常用 `/` 指令，以及一张「备注」卡。

那张卡是唯一能一次看完所有备注的地方，也是仪表盘上**唯一能改群备注**的地方：选「用户」或「群」，填号码和名字，保存；右侧「清除」去掉备注。

## 空态与加载

列表空、筛选无结果、主从页右侧未选中、以及内容区首次加载，统一走共享组件：

- `EmptyState`：`panel`（虚线框）、`inline`（列表栏）、`select`（从左侧选）
- `LoadingState`：内容区骨架，带 `aria-busy`

页面不要再手写一长串 `text-muted-foreground` 空段落。安全说明（不触网、不进 outbox、仅查看不读历史）放在 `detail` 里保留。

## 用户页

左侧列表优先显示备注，没有备注才只显示 QQ。搜索框可以打备注或 QQ。

点开一个人后，在身份卡里写备注并保存。保存不会发 QQ，也不会改回复权限。

## 其它页

这些页面的 QQ 和群号会带上你写过的备注：记忆、会话检查、汇报与审批、隐私审计、统计分析、聊天记录、消息链路、主动消息、资料炼化。

配额页有自己的「备注名」，那是配额覆盖的独立字段，和这里的备注不是同一个东西。

## 备注的边界

备注只给你认人。它不会进模型上下文、不会变成人格或记忆，也不会改变谁能被自动回复。
