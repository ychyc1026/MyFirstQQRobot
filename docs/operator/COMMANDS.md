# 主号指令

只在主号私聊机器人时有效。高风险动作仍要 `/确认 <审批码>`。

## 先看这里

| 指令 | 作用 |
| --- | --- |
| `/帮助` | 常用指令和手册入口 |
| `/状态` | 身份与好友概览 |
| `/机器人 状态` | 回复模式、是否暂停 |
| `/机器人 暂停` | 立刻停模型和外发 |
| `/机器人 恢复` | 从急停恢复 |
| `/模型 状态` | 只读模型路由 |

## 认人

| 指令 | 作用 |
| --- | --- |
| `/用户 <QQ> 状态` | 看授权和关系 |
| `/用户 <QQ> 备注 <名字>` | 给这个人起你认得的名字 |
| `/用户 <QQ> 备注 清除` | 去掉备注 |
| `/群 <QQ> 备注 <名字>` | 给群起你认得的名字 |
| `/群 <QQ> 备注 清除` | 去掉群备注 |

## 用户授权

| 指令 | 作用 |
| --- | --- |
| `/用户 <QQ> 标记旧友` / `新友` / `非好友` | 手动改关系 |
| `/用户 <QQ> 恢复自动判定` | 取消手动标记 |
| `/用户 <QQ> 历史 禁止` / `仅文件` | 历史策略 |
| `/用户 <QQ> 历史 一次授权 <条数>` | 一次历史额度 |
| `/用户 <QQ> 历史 拉取` | 按已有额度拉一次，只记条数 |
| `/用户 <QQ> 空间资料 状态` | 看空间授权 |
| `/用户 <QQ> 空间资料 预览` | 指定后才翻空间 |
| `/用户 <QQ> 空间资料 禁止` | 关掉这个人的空间采集 |

## 确认

| 指令 | 作用 |
| --- | --- |
| `/确认 <审批码>` | 批准 |
| `/拒绝 <审批码>` | 拒绝 |

## 外发、主动、空间、汇报

| 指令 | 作用 |
| --- | --- |
| `/外发 状态` / `暂停` / `恢复` | 出站发送 |
| `/主动 自动 状态` | 主动调度 |
| `/主动 创建 <QQ> <YYYY-MM-DD HH:MM> <内容>` | 预约主动私聊 |
| `/空间 队列` | 说说任务 |
| `/空间 发布 <内容>` | 先出审批码 |
| `/汇报 队列` | 主号汇报 |

更细的空间、主动、图片、资料指令仍以 `docs/OWNER_CONTROL_AND_QZONE.md` 为准。本页是主号日常入口。
