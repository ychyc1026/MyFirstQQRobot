# 可视化与主号控制规范

## 单一控制面

QQ 指令和仪表盘不能各写一套逻辑。它们只负责把操作转换为统一 `Command`，最终进入相同的鉴权、审批、状态机和审计服务。

```text
主控 QQ 指令 ─┐
               ├─> 统一命令总线 ─> 鉴权 ─> 审批/策略 ─> 执行 ─> 审计/汇报
YCH 仪表盘 ───┘
```

统一命令总线已经在用户身份与隐私模块落地。每条命令保存来源（`owner_qq` 或 `dashboard`）、操作者、参数、处理状态和结果；同一 QQ 消息重复上报不会重复执行。

因此，同一任务在 QQ 中批准后，仪表盘必须立即显示已批准；仪表盘暂停后，QQ 查询必须返回暂停状态。

## 每个页面的固定能力

- 状态：当前模式、连接、最后成功与最后失败；
- 待办：需要主控决定的事项；
- 策略：谁可以做什么、何时自动执行；
- 历史：输入、决策、执行和结果时间线；
- 控制：暂停、恢复、重试、撤销；
- 数据：来源、导出、删除、保留期；
- 诊断：失败原因和建议操作。

## 危险等级

| 等级 | 示例 | 默认要求 |
|---|---|---|
| 低 | 查看状态、生成草稿 | 主控身份或本机后台会话 |
| 中 | 修改用户策略、导入资料 | 审计 + 明确确认 |
| 高 | 发送主动消息、发布空间、批量读取历史 | 二次确认或已批准规则 |
| 极高 | 批量删除、导出全部隐私数据、切换自动模式 | 二次确认 + 短时审批码 + 可回滚备份 |

## 仪表盘视觉状态

状态不能只靠颜色表达，必须同时使用文字和图标：

- 观察：中性蓝灰；
- 影子：紫色；
- 待审批：橙色；
- 自动：绿色；
- 警告：琥珀色；
- 紧急锁定/失败：红色。

危险按钮不与普通按钮并排混淆；发布、删除、批量读取和自动模式都展示影响范围与可恢复性。

## 主控 QQ 命令规范

- 确定性管理命令以 `/` 开头；
- 自然语言只能生成建议或草稿，不能直接执行高风险动作；
- 所有命令返回命令 ID，方便在仪表盘追踪；
- 长结果只返回摘要和仪表盘定位信息；
- 重复命令通过来源消息 ID 防重；
- 主控号在群聊中的文本不作为管理命令；
- 紧急命令优先级最高，但仍写入审计。
