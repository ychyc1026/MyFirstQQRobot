# YCH 当前实现状态

更新时间：2026-09-05

## 固定身份

- 品牌：YCH（署名锁定）
- 开发者、创造者：维护者（署名锁定）
- 主控 / 机器人 QQ：实例可配，`.env` 只空库播种，之后以账号分区为准
- NapCat：4.18.18

产品署名不可被配置、人格、导入文件、用户记忆或模型输出覆盖。主号与机器人 QQ
不再写死。对外仅在相关问题出现时自然说明署名，不无关地反复强调。

## 默认安全状态

- 消息入站：允许存储，但当前 NapCat 反向 WebSocket 未启用
- 普通回复：生产运行时已实现，默认 `observe_only` + 持久急停 + 配置上限锁定，不会触网或外发
- 主动消息调度：关闭
- durable outbox 真实发送：关闭
- QQ 空间发布：关闭
- 主号自动汇报：关闭
- 隐私任务执行：关闭
- 历史消息读取：默认拒绝
- QQ 空间用户资料采集：关闭
- 扫描 PDF OCR：关闭
- 图片内容审核：关闭
- 图片孤儿巡检：关闭
- 影子推理：仓库默认关闭；本机 `.env` 可开硅基流动对话/识图影子

这些开关不会因为程序重启或创建管理员会话而自动打开。

## 已实现

### 控制与安全

- 主号 QQ 与仪表盘共用控制命令服务、审批状态机和审计记录。
- 后台长期令牌只用于换取短时会话，业务 API 不接受长期令牌。
- 短时会话可立即注销，数据库只保存令牌哈希。
- 好友基线必须先预览再审批；当前没有对真实好友列表执行预览。
- 用户汇总与隐私状态属于管理员数据，未登录请求返回 401；不再作为公开状态接口暴露。

### 身份、历史与隐私

- 用户状态为 `existing_friend / new_friend / unknown / not_friend`，未知不会被猜成新好友。
- 主控人工覆盖可显式解除；系统只依据最近的好友基线或好友添加强证据恢复，没有强证据就回到 `unknown`。
- 历史访问按用户授权，默认 `deny`；一次性授权原子消费。
- 历史一次/范围授权限制为 1–500 条；日期范围必须是合法 ISO 日期且开始日期不晚于结束日期，申请和批准时均再次校验。
- 隐私导出生成本地 JSON 数据包及 SHA-256 校验值。
- 访问决定可按用户、允许/拒绝和数据类别查询；API 返回用途、调用器和脱敏策略理由，不返回消息正文。
- 导出和删除前备份可重新校验路径边界、字节数、SHA-256、UTF-8 JSON 与 `ych-privacy-bundle-v1` 结构。
- 上传原文件会进入独立 ZIP，逐文件校验大小、SHA-256 和 CRC；源文件完整性不符时在数据库删除前中止。
- 当前仍不支持一键恢复：关系 ID 可能冲突，隐私墓碑与删除审计不可逆；恢复必须重新审批并选择性重建。
- `privacy_subject_links` 通过结构化 `user_qq/target_qq` 字段关联命令、审批和审计，不再以 JSON 文本 `LIKE` 猜测删除范围。
- 隐私删除先生成备份，再在事务内清理用户相关数据。
- 删除影响预览涵盖消息、画像、人格、记忆、控制命令、审批、主动消息、定向空间帖
  （含运行时、事件、审批、主号报告和审计）、主号报告运行时/事件，以及空间资料授权/快照。
  好友可见/公开说说不会仅因正文出现 QQ 号被删除。
- 隐私执行器默认关闭，未启用时不会领取任务。

### 人格

- 全局人工人格、单用户人工人格、文件派生人格、用户理解资料严格分层。
- “关于用户的事实”不会被当作机器人指令。
- 单用户人格和用户理解只进入对应用户的私聊上下文。
- 群聊只允许加载全局人格，不加载任何个人画像或个人记忆。
- 后台 API 已支持人工简洁定义、版本递增和上下文预览。
- 后台提供只读核心身份接口，不存在修改接口。

### 长资料炼化

- 支持 TXT、Markdown、JSON、CSV、HTML、DOCX、带文本层 PDF，以及默认可关闭的扫描 PDF OCR。
- 常见 JSON/CSV 聊天导出会规范成时间、发送者和正文；数组/包裹对象走流式解析，
  并限制记录数；非聊天大 JSON 拒绝急切加载。另支持 QQ 电脑版 TXT、OneBot/NapCat JSON
  （`raw_message` / 嵌套 sender / Unix 时间）和结构化 QQ HTML；普通笔记/网页不误判。
  OCR 默认关闭，测试只用假引擎；有文本层的页面不会调用 OCR，扫描页在关闭时明确拒绝。
- 文件去路径化，限制原始大小、PDF 页数、DOCX 条目/解压体积和可疑压缩比。
- 原文件 SHA-256、文本块 SHA-256、块顺序和解析格式均持久化。
- “认识用户”和“设计面对该用户的人格”从任务创建到输出 schema 严格分离。
- 块级租约和检查点支持失败续跑，已完成块不会重复调用模型。
- 每条证据必须是对应原文块的短引用；汇总不能创造未验证引用。
- 模型未配置时任务停在 `awaiting_model_config`，不写入画像、人格或记忆。
- 处理结果生成统一审批与主号待办；批准后才版本化写入。
- 派生人格在块级和汇总级拒绝覆盖开发者、创造者、主号或机器人身份。
- 默认关闭的常驻 worker 已完成：串行处理、租约接管、指数退避、最大尝试和运行状态。
- 后台与主号均可查看、暂停和恢复 worker；暂停状态写入 schema v18，重启后仍保持。

### 记忆

- 记忆按事实、偏好、关系事件、会话摘要分层。
- 非人工来源默认进入候选状态，不直接影响回复。
- 同键同值自动去重；同键不同值进入冲突，不静默覆盖。
- 冲突支持保留旧值、使用新值、两者都忘记，并记录审计。
- 忘记是可审计的逻辑状态；隐私删除才执行硬删除。
- 群聊和非对应私聊无法检索个人记忆。

### 模型网关与影子推理

- 对话、识图、图片生成、统计使用独立协议、地址、密钥、型号、启用开关、超时和重试配置。
- 识图走多模态 `chat/completions`，不要填进文生图。官方人民币鉴定候选是 `zai-org/GLM-4.5V`，不是无官方人民币单价的 `Qwen/Qwen3-VL-8B-Instruct`。
- 模型资格鉴定已落地并完成四条有界合成套件实跑：对话 `deepseek-ai/DeepSeek-V3.2`、识图 `zai-org/GLM-4.5V`、文生图 `Tongyi-MAI/Z-Image-Turbo`、统计 `Qwen/Qwen3.5-35B-A3B`。请求绑定编译后的 YCH 身份。通过不是生产启用。
- 表情包只检索 `storage/stickers/<标签>/` 下的 png/gif/webp，同标签随机抽一张；不是系统 emoji，也不用文生图。
- 群聊影子只在 @ 机器人 QQ 时生成；私聊不要求 @。
- 仪表盘可给每个用户设回复句数区间和每句长短（默认 1 句，最多 10）；一次回复拆成多条气泡预览，仍不进 outbox。
- 已实现可选的 OpenAI-compatible 对话与图片 HTTP 适配器。
- 429、408、超时和常见 5xx 使用有界重试；错误不记录响应正文或 API 密钥。
- 对话适配器记录 provider request ID、输入 token 和输出 token。
- 图片适配器可解析 URL/base64；任务层只接受经校验的 base64 PNG/JPEG，不自动抓取 URL。
- 影子推理只生成 `reply_candidates`，没有进入 outbox 的转换方法。
- 主号可用 `/影子 状态|最近|查看|重跑`；后台可查看运行详情并对已存消息显式重跑。
- 显式重跑失败只发 `info` 汇报；真实模型网络与影子开关仍默认关闭。
- 提示词将核心身份、人格、不可信用户参考与用户消息分层。
- FakeGateway 和 MockTransport 测试全程不访问外部网络。
- 聊天/识图/图片拥有独立的持久化每日请求预算；聊天与识图另有独立 token 预算。
- 连续失败熔断、冷却后单探测和过期调用租约均已实现，重启不会清零状态。
- 保护事件不存 Prompt、正文、图片或密钥，只保留用量与脱敏错误类型。
- 图片任务支持本地存储、SHA-256/尺寸复核、认证预览、统一审批和主号待办报告。
- 图片批准只改变任务状态，不会进入 outbox、发送 QQ 或发布空间。
- 默认可关闭的假内容审核、过期审批续期和孤儿文件巡检 worker 已落地；真实审核网络关闭。
- 主号可用 `/图片 创建|生成|状态|续期|巡检` 和统一确认/拒绝命令控制。

### 主动消息与真实日历调度

- SQLite schema v14 已加入每用户主动策略、持久任务和投递事件。
- 计划时间是带时区的真实日历时间，不依赖进程启动时间；重启后按任务策略恢复。
- 默认 `skip`，另支持宽限补入 outbox 和重新请求主号审批。
- 新用户默认关闭；默认安静时段 22:00–08:00、每日 3 条、最短间隔 1 小时。
- 任务审批、用户权限、调度 worker 和真实 outbox worker 是相互独立的安全关卡。
- 调度入 outbox 使用稳定幂等键；发送失败指数退避并限制尝试次数。
- 待发送 outbox 可以原子撤销；已领取/已发送任务不会伪装撤销成功。
- 主号可创建、查询、取消、启停用户权限，并分别控制调度和真实外发 worker。
- 后台已有任务日历查询、详情时间线、用户策略、聚合状态和两个 worker 控制 API。
- 隐私导出、删除影响预览与硬删除已覆盖任务正文、策略、事件、审批和报告。
- 完整语义和接口见 `docs/PROACTIVE_MESSAGES.md`；尚未触碰真实 QQ。

### QQ 空间任务与发布

- SQLite schema v15 已加入全站调度策略、帖子运行时和事件。
- 草稿不审批、不触网；发布必须主号确认，再经真实日历、安静时段和限频。
- worker 开关与 `YCH_QZONE_PUBLISH_ENABLED` 独立；默认都关闭。
- 指定/排除好友可见必须提供 `target_uins`；发布中超时只调用一次并进入不确定状态。
- 后台已有日历、详情、策略、撤销和 worker API；主号可队列/草稿/发布/定时/取消/撤销/暂停/恢复。
- 已发布且有 `tid` 的帖经主号确认后才能调用 `delete_qzone_msg`；超时或中断进入 `delete_uncertain`，禁止自动重试。
- 隐私导出与删除只覆盖定向给该用户的空间帖及其关联审批、报告、事件和审计。
- 完整语义见 `docs/QZONE_PUBLISHING.md`；尚未触碰真实 QQ 空间。

### 主号汇报去重与 outbox 投递

- SQLite schema v16 已加入投递策略、汇报运行时和事件，不改动既有 `owner_reports` 表结构。
- 相同 `dedupe_key` 在窗口内合并未确认汇报；digest 延迟到下一个本地 09:00，不合成一条 QQ。
- 默认 `action_required`/`critical` 立即投递，`warning`/`info` 走 digest；可改为仅仪表盘。
- worker、`YCH_OWNER_REPORTS_ENABLED` 和 `YCH_OUTBOUND_ENABLED` 是三道独立关卡，默认关闭。
- 每条汇报只入队一次；outbox 可自重试，耗尽后标记失败，不再重新入队。
- 后台已有摘要、策略、worker 控制 API；主号可队列/状态/已读/暂停/恢复。
- 隐私导出与删除覆盖与用户相关的报告运行时和事件。
- 完整语义见 `docs/OWNER_REPORTS.md`；尚未向真实主号发消息。

### QQ 空间用户资料读取

- SQLite schema v17 已加入逐用户授权和资料快照。
- 全局开关 `YCH_QZONE_PROFILE_COLLECTION_ENABLED` 默认关闭；好友关系不自动授权。
- 支持 `deny` / `one_time` / `ttl`；一次授权原子消费，限期到期立即拒绝。
- 预览只保存快照并写入带过期时间的 `qzone_derived` 候选记忆，不写 active 记忆或人格。
- 主号可查询、禁止、一次/限期授权和预览；一次/限期需 30 分钟审批。
- 后台可查看授权/快照/候选，并在开关与授权通过后预览。
- 完整语义见 `docs/QZONE_PROFILE.md`；尚未触碰真实 QQ 空间。

### Worker 运行时暂停

- SQLite schema v18 已加入 `worker_runtime_state`。
- 资料、主动消息、空间、主号汇报、外发和图片孤儿巡检 worker 的暂停都会写入数据库。
- 进程重启后仍保持暂停，直到主号或仪表盘显式恢复；`.env` 总开关仍是独立关卡。

### 管理仪表盘

- `frontend/` 使用 Vite + React + TypeScript + Tailwind；视觉为暖纸张底、黑色信息层级、
  焦橙强调和编辑感卡片，并支持雾蓝、竹绿、木红、暖棕主题。
- 登录用 `YCH_ADMIN_ACCESS_TOKEN` 换短时会话；总览看待办，近况看操作/程序状态。
- 「账号」「额度」页已接 API：改主号、启停多机器人、按用户/群改日限额与今天追加。
- 「汇报与审批」页已接 API：左队列右详情，确认/拒绝/已读与主号同一状态机；确认不会立刻发 QQ。
- 「用户身份与隐私」页已接完整控制面：证据来源/可信度、好友基线预览、主控标记、历史禁止/仅文件/一次/范围授权、空间禁止/一次/限期授权和读取预览、冻结、导出与删除。真实读取动作有明确提示，危险动作进入审批。
- 「隐私与访问审计」页已接访问决定筛选、导出/删除任务列表、产物完整性校验和恢复边界说明；不展示聊天或空间正文。
- 「系统与审计」页新增数据库预检卡：当前/目标 schema、quick check、外键结果、迁移备份开关和最近备份。
- 「人格」页已接 API：全局/单用户人工定义、资料派生只读、私聊/群上下文预览（群不加载个人层）。
- 「记忆」页已接 API：按用户浏览、人工写入、逻辑忘记、冲突待办（保留旧值/使用新值/两者都忘记）、私聊/群检索预览（群应为空）。
- 「资料炼化」页已接 API：上传、任务列表/详情、显式处理、批准预览、worker 状态/单次/暂停/恢复；默认停在 awaiting_model_config。
- 「会话」页已接 API：上下文检查器（私聊/群隔离、主控 QQ 认证）、影子运行/候选详情、显式重跑；默认关闭不触网、不进 outbox。
- 「空间工作台」页已接 API：草稿/发布审批、日历队列、取消、撤销申请、安静时段策略、worker 状态/单次/暂停/恢复；默认关闭且禁止自动网络重试。
- 统计、聊天记录、日记和材料页已接 API；关闭的能力显示「关闭」，不显示 0。
- 后端新增只读近况聚合，按 `Asia/Shanghai` 自然日分桶，不进 outbox、不触发模型。
- 「消息链路」页展示 reply readiness、阶段筛选、脱敏任务详情、上下文来源和送达轨迹；
  只读页面不提供启用按钮，真实 Worker 未接线时明确显示阻塞。

### 可恢复回复链路

- 相邻入站消息按会话合并为持久 reply run；上下文、模型、规划、outbox 和送达使用显式阶段。
- 上下文来源按核心身份、授权、当前会话、人格、资料、记忆和历史分段，先隔离验证再渲染。
- fake-first Worker、确定性多气泡计划和事务 outbox 均使用稳定幂等键；测试不访问真实模型或 QQ。
- 明确拒绝与送达不明都会终止任务；送达不明隔离且禁止盲重发。
- 上下文组装阶段的过期租约支持重启/休眠后接管；事件重放、并发领取和持久暂停已覆盖。
- 只读 API 与仪表盘剔除完整上下文、候选/回复正文、prompt hash、原始 OneBot 和 lease token。

### 账号分区与客户额度

- schema v21：`instance_owner`、`bots`、`chat_quota_overrides`、`chat_quota_notices`、`user_reply_style_policies`；
  `inference_runs.bot_qq`；会话键为 `{bot_qq}:{kind}:{peer}`。
- 一份进程一个主号可改；多独立机器人可启停，换号不改写旧号历史。
- 私聊默认每天 50 万 token，群默认 200 万；均可单独覆盖，另可追加「今天额度」。
- 私聊超限：停模型，主号通知一次，用户默认回复一次（文案可改）；加额后再超再通知。
- 群超限：静默停模型，不通知主号，不在群里说明。
- 主号命令：`/额度 状态`、`/额度 今天 <QQ> <token>`、`/额度 用户 <QQ> <token>`、
  `/额度 群 <群号> <token>`。
- 外发总开关关闭时，通知与默认回复只落库。详见
  `docs/superpowers/specs/2026-08-13-account-partitions-and-quotas-design.md`。

### 统计、聊天记录、日记与主动材料

- 统计按上海自然日提供今日、7 日、30 日范围，展示私聊人数、群聊数、活跃会话、图片、
  消息趋势和 token 分布；按日摘要有独立 `YCH_STATS_*` 模型路由，默认关闭时生成规则摘要。
- 已成功投递的 outbox 消息会幂等回写为出站消息，因此聊天记录可展示真正的双向链路。
- YCH 日记按上海自然日保存；当天未发仍为待发，跨日自动过期，日记为空不发送。
- 主动材料要求标题、正文和上传者说明；模型核对第一行必须精确为 `MATCH` 才能启用，
  联网搜索是独立默认关闭开关。
- 普通主动消息、每日自动材料/上下文、发送 YCH 当日日记是三个独立逐用户授权；后两项
  默认为关闭，安静时段判断在搜索和模型调用之前。
- 主号新增 `/主动 用户 <QQ> 状态`、`/主动 内容 <QQ> 开启|关闭`、
  `/主动 日记 <QQ> 开启|关闭`，后台在用户策略卡片中提供同样的可视化开关。
- 日摘要记录来源对象 QQ。用户隐私导出、影响预览和删除会覆盖账号分区后的双向私聊、
  推理候选与含该用户的派生摘要，避免旧会话键假设造成残留。

- `GET/PUT /api/v1/accounts...`：主号、机器人启停与默认额度/超限回复
- `GET/PUT/POST /api/v1/quotas...`：按用户/群日限额与今天追加
