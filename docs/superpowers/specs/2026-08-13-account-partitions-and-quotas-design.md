# 账号分区与客户额度

更新时间：2026-08-13

开源实例一份进程只有一个主号，主号 QQ 可改；主号下可挂多个独立机器人。
QQ 不再写死在代码里。产品署名仍为 YCH / 维护者，不能被人格或用户消息覆盖。

## 账号

- `.env` 的 `YCH_OWNER_QQ` / `YCH_BOT_QQ` 只在空库时播种。
- 库表 `instance_owner`（单行）+ `bots`（QQ、备注、启用、默认额度、超限回复）。
- 换号 = 停用 A、启用或新增 B；不把 A 的历史改写成 B。
- 入站按 OneBot `self_id` 匹配已启用机器人；未知号丢弃。
- 控制命令只认当前主号 QQ。

## 额度（上海自然日）

| 对象 | 默认 | 超限 |
|---|---|---|
| 私聊用户 | 50 万 token/天，可改 | 停模型；主号通知一次（QQ+备注/仪表盘名）；给用户默认回复一次（可编辑） |
| 群 | 200 万 token/天，可按群改 | 停模型；不通知主号；不在群里说话 |

当天可用 = 日限额 + 今天临时追加（过 0 点清零）。主号/仪表盘追加今天额度后可再聊；再次用超则再通知/再回复用户（仅私聊）。

外发总开关关闭时，通知与默认回复只落库，不真发 QQ。
