# 主控 QQ、汇报机制与 QQ 空间发布

## 身份边界

- 主控号：`2000000001`；
- 执行机器人：`2000000002`；
- 只有主控号与机器人的私聊消息可以成为管理指令；
- 主控号在群内说出的相同文字仍按普通群消息处理，防止公开群聊误操作；
- 其他账号伪造命令、转发命令或引用主控消息都不获得权限；
- 每条控制命令、审批、发布、撤销和失败都写入审计记录。

主号日常入口和完整常用表在 `docs/operator/`，仪表盘「操作手册」同步展示。

`/空间 发布` 默认不是绕过审批的危险快捷键。机器人先返回最终正文、图片、可见范围和审批码；主控回复 `/确认 <审批码>` 后才进入发布队列。以后可增加语音/自然语言指挥，但自然语言只能生成候选命令，不能绕过确定性命令和权限校验。

图片批准只允许本地产物进入后续候选池，不等于发布空间或发送给用户；目标使用动作仍需
独立策略与审批。

主动消息使用真实日历时间，不按程序启动时长计算。创建任务、批准任务、开启目标用户
权限、启用主动调度和启用真实外发是独立关卡；完整规则见 `docs/PROACTIVE_MESSAGES.md`。

## 空间状态机

```text
草稿
  └─> 待主控审批
        ├─> 拒绝 / 取消
        └─> 已批准
              ├─> 等待计划时间 / 安静时段 / 限频
              └─> 发布中
                    ├─> 已发布（保存 tid）
                    └─> 发布结果不确定（禁止自动重试，向主控汇报）

已发布 ──主控确认撤销──> 删除中
                              ├─> 已删除（保留 tid 审计）
                              └─> 删除结果不确定（禁止自动重试）
```

NapCat 4.18.18 的 `send_qzone_msg` 支持正文、图片、查看权限和指定 QQ，成功后返回 `tid`；`delete_qzone_msg` 使用 `tid` 删除。YCH 必须保存 `tid`、实际请求摘要和结果，不能只显示“调用成功”。

## 自动发布控制

自动发布分三层，默认只开放第一层：

1. `锁定模式`：自动系统只能生成草稿，每条都由主控确认；
2. `策略模式`：主控可以批准一条有范围和期限的规则，例如“每天最多一条、只在 09:00–21:00、仅公开指定主题”；越界仍需审批；
3. `暂停模式`：所有发布任务冻结，但草稿、汇报和审计继续工作。

任何模式都设置每日上限、最短发布间隔、内容重复检测和敏感信息检查。程序关机错过计划时间时默认不补发，转为“错过计划”并询问主控。

## 向主号汇报

汇报不是把所有日志轰炸给主控，而是分级处理：

- `需操作`：空间审批、资料导入确认、人格冲突等，立即私聊；
- `严重`：登录失效、连续发布失败、鉴权异常，立即私聊并在仪表盘置顶；
- `警告`：单次任务失败、空间权限变化，合并后汇报；
- `信息`：正常发布、每日运行摘要，可配置即时或每日汇总。

每条汇报带唯一 ID、原因、建议操作和关联任务。相同故障在时间窗口内合并，避免循环刷屏；向主号发送汇报本身失败时只落库并在仪表盘告警，不能无限重试。

本地第一轮已实现：schema v16 运行时/事件、即时/digest/仅仪表盘三类策略、worker 与
`YCH_OWNER_REPORTS_ENABLED` / `YCH_OUTBOUND_ENABLED` 三道关卡、一次入队后不再因失败
重新入队。完整规则见 `docs/OWNER_REPORTS.md`。

视觉与技术选型见 `frontend/VISUAL_LANGUAGE.md`。总览 / 近况第一刀已落地。

## 仪表盘信息架构

### 主控中心

- 机器人在线状态、NapCat 连接、最近严重告警；
- 待审批数量和快捷处理；
- 全局暂停、静默模式、恢复按钮；
- 最近来自 QQ 主控号的命令与执行结果。

### 空间工作台

- 草稿、待审批、已计划、发布中、已发布、失败六个视图；
- 正文与图片预览、可见范围、来源和生成依据；
- 批准、修改、拒绝、改期、撤销、重试；
- 发布日历、频率限制、错过计划处理；
- `tid`、发布时间、接口结果和完整审计时间线。

### 汇报中心

- 按需操作、严重、警告、信息分栏；
- QQ 是否已送达、主控是否确认；
- 故障合并次数、第一次/最后一次发生时间；
- 可从汇报直接跳转到相关用户、任务、空间草稿或配置。

空间任务使用真实日历时间。草稿不审批；发布必须主号确认，再经 worker 开关和
`YCH_QZONE_PUBLISH_ENABLED`。发布中超时禁止自动重试。完整规则见
`docs/QZONE_PUBLISHING.md`。
