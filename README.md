# MyFirstQQRobot
一个基于 Python 与 napcat 开发的轻量级 QQ 机器人，
支持关键词自动回复 + AI 大模型 API 智能对话，适合大一入门练手。

## 功能
- 关键词自动回复
- 骰子随机数
- 签到功能
- 自定义问答规则
- AI 智能聊天对话（通过第三方 AI API 实现）
- 私聊/群聊消息监听
- 可部署在 Linux 云服务器 24 小时运行

## 技术栈
- Python
- go-cqhttp
- HTTP API
- AI 大模型 API 接口
- Linux 服务器部署
- Git & GitHub

## 项目收获
- 理解 QQ 机器人消息收发原理
- 掌握 Python 基础逻辑与 API 调用方式
- 学会对接第三方 AI 接口实现智能对话
- 掌握项目从开发到服务器上线的完整流程
- 提升实战能力与问题排查能力

## 适用场景
- 个人 QQ 自动聊天助手
- 群聊娱乐互动
- 接入 AI 实现智能陪聊
- 计算机专业大一入门实战项目
