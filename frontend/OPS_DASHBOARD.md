# 运行近况与操作可视化

更新时间：2026-08-13

总览负责「今天必须决定什么」。**近况**负责「人和程序刚才做了什么」。
不要用粉丝、营收、完成率这类空 KPI。所有数字按 `Asia/Shanghai` 自然日。

开关关闭时显示「关闭」，不要显示 `0` 假装系统很健康。

## 放在哪

- 一级导航新增 **近况**，排在总览之后。
- 总览底部只放三枚摘要（待处理 / 今日入库 / 异常）+ 迷你趋势，点进去到近况全页。
- 系统与审计仍管开关、身份锁定、审计检索；不和近况抢图表。

## 一眼区（今日）

| 指标 | 含义 | 主要来源 |
|---|---|---|
| 待你处理 | 待审批 + `action_required`/`critical` 未读汇报 | `approval_requests` + `owner_reports` |
| 今日入库 | 今天成功写入的入站消息 | `messages` / inbound events |
| 异常 | 空间不确定 + outbox 失败 + 熔断打开 + 汇报投递失败 | qzone / outbox / protection / reports |

副徽章（同一行小字，不是大数字）：运行模式、OneBot 是否连接、最后事件时间。

## 趋势区（默认近 7 日）

一张白卡 + 细折线（焦橙 / 炭黑 / 暖灰最多三条）：

1. 入库消息
2. 主号或仪表盘控制命令
3. 审批处理（确认+拒绝）

可切 今日 / 7 日 / 30 日。无数据时画空坐标 + 「还没有事件」，不要假线。

## 分路况（三枚，与趋势卡同一视觉）

| 块 | 开着时 | 关着时 |
|---|---|---|
| 影子 | 成功 / 失败 / 跳过 | 关闭 |
| 外发 | 待发 / 失败 | 关闭 |
| 空间 | 发布中 / 不确定 / 待删 | 发布关闭 |

## 右栏

1. **系统锁定**：YCH / 维护者署名锁定；当前主号与已启用机器人来自账号分区，可改。
2. **Worker**：资料、主动、空间、汇报、外发、图片巡检 → 运行中 / 已暂停 / 未启用。
3. **最近操作**：最多 8 条，来自主号 QQ、仪表盘、worker；点一条跳到对应页。

## 模型用量（近况页下半，可折叠）

聊天 / 图片分列：当日请求 vs 限额、token（仅聊天）、熔断状态。数据来自已有
`/api/v1/models/protection`。未配置模型时写「未配置」，不画空饼图。

## 后端

只读聚合已落地，不改业务语义：

```text
GET /api/v1/ops/snapshot   # 今日待处理/入库/异常 + 分路况 + worker
GET /api/v1/ops/series     # days=1|7|30 入库/命令/审批
GET /api/v1/ops/activity   # 最近操作时间线
```

按日桶用 `YCH_TIMEZONE`。不进 outbox，不触发模型，不读真实 QQ。
CORS 已允许本机 Vite `:5173`；开发时也可用 Vite 代理 `/api`。

## 消息链路观察页

一级导航「观察」下的 `/pipeline` 是回复链路的只读运维面：readiness 大卡优先显示所有
正式启用阻塞项，下方按阶段筛选 reply run，并展示脱敏失败、上下文来源、模型统计和送达轨迹。
页面不显示上下文/候选/回复全文、原始 OneBot 或 lease token，也不提供启用、重试或真实发送按钮。

视觉验收必须使用临时数据库和假适配器；入站、模型网络、outbox、空间、主动消息和主号汇报
均保持关闭。`delivery_unknown` 使用警示色并明确禁止盲重发。
