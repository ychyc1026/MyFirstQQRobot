# YCH 仪表盘信息架构

## 固定身份

YCH 是品牌与开发者身份。创造者为维护者，主号为 2000000001。固定身份在总览、账号和系统页只读展示，不能被普通配置或用户资料覆盖。

## 分组导航

1. 概览与运行：总览、操作手册、运行近况、消息链路、统计分析。
2. 用户与上下文：用户、人格、记忆、配额。
3. 对话与知识：会话检查、聊天记录、资料炼化、汇报与审批。
4. 自动化：主动消息、YCH 日记、主动材料、QQ 空间。
5. 系统：操作日志、账号、隐私审计、系统设置。

桌面使用固定侧栏；窄屏使用 Sheet 导航。顶栏提供面包屑、只读健康摘要、明暗模式、用户菜单和安全命令搜索。

## 页面职责

- 操作手册列出主号日常规则和 `/` 指令，并集中管理备注：唯一能一次看完全部备注、也是唯一能改群备注的地方；仓库副本在 `docs/operator/`。
- 用户页负责好友证据、历史/空间授权、冻结和该用户的备注；备注只给操作者认人，不进模型，也不改变自动回复资格。
- 列出 QQ 或群号的页面都优先显示备注：用户、记忆、会话检查、汇报与审批、隐私审计、统计分析、聊天记录、消息链路、主动消息、资料炼化。配额页的「备注名」是配额覆盖自带字段，与操作者备注不同源。
- 总览只聚合真实指标、待办、固定身份、工作进程和事件摘要。
- 运行近况与统计展示服务端时间序列、worker 状态及关闭/不可用状态。
- 操作日志集中展示最近的仪表盘审计、主号命令和主号汇报；运行近况只保留三条中文摘要与入口。
- 消息链路展示模式、就绪门禁、运行记录、详情和投递状态；观察模式不能伪装成已启用。
- 人格与记忆按全局、用户、群聊分层；群聊不得注入个人层。
- 资料炼化支持长文件任务、证据、预览和批准，但不会因上传自动触网。
- 汇报与审批、主动消息、QQ 空间沿用后端预览/确认/撤销状态机；主号与仪表盘看到同一状态。
- 系统与隐私页负责只读配置、访问审计、备份校验、迁移预检及高风险操作。

页面必须提供加载、空、失败、禁用、断连、过期和成功状态，不展示原始密钥、会话令牌、完整私聊正文或可复用确认材料。

空列表、筛选无结果、主从页未选中、内容区加载统一用 `EmptyState`（`panel` / `inline` / `select`）和 `LoadingState`，不要各页自造 muted 段落。安全语义文案放在 empty `detail` 里保留。

前端测试与组件/页面同目录，共享助手在 `src/test/support/`，说明见 `src/test/README.md`。
