# 本地表情包素材

要放的是图片文件（png / gif / webp），不是系统 emoji 字符，也不是键盘表情。
按标签分子目录放置，文件名随意：

```text
storage/stickers/开心/01.png
storage/stickers/狗头/a.gif
```

允许标签：开心、委屈、狗头、无语、大笑、emo、可爱、生气、惊讶、晚安。

本机已预置 Microsoft Fluent Emoji 3D（MIT）各约 22 张，风格干净，自行删选即可。
模型只输出【关键词】，后端按标签检索这里的文件。不要用文生图实时做表情包。
素材只在本机，不进 Git；当前不会随回复发 QQ。
